💡 Important: Configuration vs Firmware Flashing
Customizing keys, macros, hold time, or profiles? You do not need to flash firmware! All settings save directly into internal RP2040 Flash memory using the green "💾 Sync to Flash" button.
Firmware flashing (UF2) is only needed if you are upgrading the keyboard's core C++ operating system.
